# 2190151 Computer Programming Lab

Lab exercises and skill tests for **2190151 Computer Programming Lab**, Year 1 Semester 1, ADME, Chulalongkorn University (CU).

All solutions are written in **Python 3**.

## Repository Structure

| Folder | Description |
| --- | --- |
| `LAB_1_3` | Lab 1 |
| `lab2_1`, `lab2_23`, `lab2_4` | Lab 2 |
| `lab3_1` to `lab3_5` | Lab 3 |
| `lab_4_3` to `lab_4_5`, `AutoMelodyLab_4_2` | Lab 4 |
| `lab_5_1` to `lab_5_4` | Lab 5 |
| `LAB6-WIFI` | Lab 6 |
| `SKILL TEST 1` | Skill test |

Folder names follow the pattern `lab<week>_<problem>`.

## How to Run

```bash
git clone https://github.com/W1nOfGood/2190151-COMP-PROG-LAB.git
cd 2190151-COMP-PROG-LAB/<folder>
python <filename>.py
```

Most programs read their input from the keyboard with `input()` and print the result to the screen.

## Notes

- This repo is for learning and practice. Please don't copy solutions for your own graded assignments.
- Some folders (for example `lab_5_2_backup_...`) are backups of earlier versions.
